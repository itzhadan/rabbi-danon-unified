# שיעורי יום רביעי — קול הלשון

האתר והאפליקציה מציגים אזור נפרד בכתובת `/#kolhalashon`. המדיה נשמרת באחסון האתר, עם קישור למקור, תאריך השיעור וחלקים ממוספרים במידת הצורך. אין ערבוב עם שיעורי שלוש הדקות והתגובות בוואטסאפ.

## ייבוא

`kolhalashon_import.py` מקבל רשימת שיעורים שנבחרו בדף הרשמי של הרב. הוא מוריד כתובות מדיה רשמיות, בודק שהקובץ תקין, מפצל קבצים גדולים לחלקים עד 95,000,000 בתים ומעלה אותם באמצעות ההרשאה הקיימת ב־`config.json`. נדרשים Python 3.10 ומעלה, FFmpeg ו־ffprobe. אין תלות בחיבור הוואטסאפ. תמונת עטיפה בתוך MP3 אינה מסווגת כסרטון.

מבנה הקלט (כתובת המדיה צריכה להיות כתובת טרייה שהופיעה בנגן הרשמי):

```json
{"lessons":[{"id":"42852207","date":"2026-10-14","title":"כותרת השיעור","media":[{"kind":"audio","url":"https://media-cdn.kolhalashon.com/REPLACE-WITH-OBSERVED-MEDIA-URL"}]}]}
```

```bash
python3 kolhalashon_import.py < manifest.json
```

אפשר להעביר JSON בקידוד Base64 באמצעות `--base64`. לכל שיעור ניתן לצרף רשומות שמע ווידאו. כרגע נדרשים קובצי מדיה ישירים, ולא רשימות HLS. לא להמציא כתובת וידאו כאשר המקור מציע רק שמע.

מזהה השיעור, סוג המדיה ומספר החלק מונעים כפילויות בשרת. קובץ `.khl-ID-KIND.done` נוצר רק לאחר שכל החלקים אושרו. במקרה כשל, מרעננים את כתובת המקור ומריצים שוב; החלקים שכבר קיימים מדולגים. אין לשנות את מנגנון הפיצול באמצע ייבוא חלקי.

## בדיקה קבועה בשרת

`kolhalashon_sync.py` קורא את הממשק הציבורי המשמש את האתר הרשמי, עם מזהה יישום מפורש. אין צורך בדפדפן, עוגיות או מחשב ביתי פעיל. הסקריפט מסנן רק את הרב 2268, מקבל כתובות מדיה טריות בכל ייבוא ומדלג על תוכן נעול או שאסור להורדה. כשל אינו מסומן כהצלחה.

```bash
python3 -u /home/walev/rabbi-wa-bot/kolhalashon_sync.py --all --loop
```

הבוט מפעיל ומפקח על התהליך בתוך משימת ה־Always-on הקיימת ב־PythonAnywhere, בלי צורך במשימה נוספת. אפשר להפעיל את הפקודה גם בנפרד. ההפעלה הראשונה מייבאת את כל הארכיון בהדרגה; אחרי השלמה נבדקים שיעורי 30 הימים האחרונים כל שש שעות. סימון `.khl-archive.done` נוצר רק לאחר סיום ללא כשלים. אם ארכיון נכשל, הניסיון הבא משלים אותו בלי להעלות שוב חלקים שהושלמו. נעילת תהליך מונעת ייבוא מקביל. פקודה ידנית בשרת: `python3 kolhalashon_sync.py`; להשלמת הארכיון: הוסיפו `--all`.

אין צורך באוטומציית Codex לאחר הפעלת המשימה בשרת. קבצי HLS אינם נתמכים עדיין; הם נרשמים ככשל ולא כהעלאה מוצלחת. יש לבדוק את לוג המשימה לכשלים ולהריץ מחדש לאחר תיקון.

יש להשתמש רק במסגרת הרשאת בעלי התוכן להעלאה מחדש. אין לשמור במאגר סיסמאות, קובצי הגדרות פרטיים, קישורים חתומים זמניים או קובצי מדיה.

בדיקות: `python3 bot/tests/kolhalashon.test.py` משורש המאגר.
