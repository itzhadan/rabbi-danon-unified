# שיעורי יום רביעי — קול הלשון

האתר והאפליקציה מציגים אזור נפרד בכתובת `/#kolhalashon`. המדיה נשמרת באחסון האתר, עם קישור למקור, תאריך השיעור וחלקים ממוספרים במידת הצורך. אין ערבוב עם שיעורי שלוש הדקות והתגובות בוואטסאפ.

## ייבוא

`kolhalashon_import.py` מקבל רשימת שיעורים שנבחרו בדף הרשמי של הרב. הוא מוריד כתובות מדיה רשמיות, בודק שהקובץ תקין, מפצל קבצים גדולים לחלקים עד 95,000,000 בתים ומעלה אותם באמצעות ההרשאה הקיימת ב־`config.json`. נדרשים Python 3.8 ומעלה, FFmpeg ו־ffprobe. אין תלות בחיבור הוואטסאפ.

מבנה הקלט (כתובת המדיה צריכה להיות כתובת טרייה שהופיעה בנגן הרשמי):

```json
{"lessons":[{"id":"42852207","date":"2026-10-14","title":"כותרת השיעור","media":[{"kind":"audio","url":"https://media-cdn.kolhalashon.com/REPLACE-WITH-OBSERVED-MEDIA-URL"}]}]}
```

```bash
python3 kolhalashon_import.py < manifest.json
```

אפשר להעביר JSON בקידוד Base64 באמצעות `--base64`. לכל שיעור ניתן לצרף רשומות שמע ווידאו. כרגע נדרשים קובצי מדיה ישירים, ולא רשימות HLS. לא להמציא כתובת וידאו כאשר המקור מציע רק שמע.

מזהה השיעור, סוג המדיה ומספר החלק מונעים כפילויות בשרת. קובץ `.khl-ID-KIND.done` נוצר רק לאחר שכל החלקים אושרו. במקרה כשל, מרעננים את כתובת המקור ומריצים שוב; החלקים שכבר קיימים מדולגים. אין לשנות את מנגנון הפיצול באמצע ייבוא חלקי.

## בדיקה קבועה

בדיקה מתוזמנת ב־Codex פותחת את הדף הרשמי של הרב, בודקת שיעורים חדשים ותאריכים, קוראת את מקורות המדיה המוצגים בנגן ומפעילה את הסקריפט ב־PythonAnywhere. כתובות ה־CDN מוגבלות בזמן ולכן אין לשמור אותן ככתובות קבועות. ההתחברות נשארת בדפדפן; אין לייצא עוגיות או סיסמאות.

זהו תהליך משולב: הסקריפט מבצע את ההעברה בשרת, ו־Codex מגלה מדיה חדשה דרך הדפדפן. הבדיקה המתוזמנת דורשת מחשב פועל, Codex פתוח וחיבור תקף ל־PythonAnywhere; היא אינה cron עצמאי בשרת. אם נדרשת התחברות מחדש, יש להודיע למשתמש. אין להציג בדיקה שטרם התרחשה כהעלאה מוצלחת.

יש להשתמש רק במסגרת הרשאת בעלי התוכן להעלאה מחדש. אין לשמור במאגר סיסמאות, קובצי הגדרות פרטיים, קישורים חתומים זמניים או קובצי מדיה.

בדיקות: `python3 bot/tests/kolhalashon.test.py` משורש המאגר.
