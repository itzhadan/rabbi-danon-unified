# חיבור WhatsApp מחדש

הבוט פועל במשימת Always-on של PythonAnywhere בחשבון `walev`:

```sh
cd /home/walev/rabbi-wa-bot && exec /home/walev/.nvm/versions/node/v22.23.3/bin/node bot.mjs
```

אם החיבור נותק ולא חוזר, משביתים את המשימה ומוודאים שהיא נעצרה. מעבירים את `auth` לתיקיית גיבוי מקומית מוגנת, בלי להציג או להעתיק את תוכנה. מפעילים את הבוט במסוף, סורקים את הקוד בוואטסאפ דרך מכשירים מקושרים וממתינים להודעת `מחובר לוואטסאפ`.

אחרי הקישור מסיימים את מופע המסוף, מוודאים שאין מופע נוסף ומפעילים מחדש את משימת ה־Always-on. יש לוודא גם מצב Running וגם הודעת חיבור חדשה בלוג `/var/log/alwayson-log-276151.log`. אין להפעיל שני מופעים המשתמשים באותה תיקיית `auth`.

פרטי החיבור והגיבויים נשארים בשרת בלבד. אין לשמור במאגר QR, קובצי auth, config.json, סיסמאות או לוגים. קישור מחדש אינו משנה את קוד הבוט או את סינון התוכן. סנכרון ההיסטוריה כפוף לזמינות של WhatsApp ולמגבלת הגיל שבקוד.

סנכרון קול הלשון פועל במשימה שעתית נפרדת ואינו תלוי בחיבור זה.
