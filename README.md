# הרב יוסף דנון — אתר, אפליקציה ובוט

מאגר מאוחד של שלושת חלקי המערכת, כולל היסטוריית Git המקורית.

| תיקייה | תפקיד | הפעלה |
| --- | --- | --- |
| `website/` | אתר ושרת Cloudflare Worker | Cloudflare |
| `app/` | אפליקציית Flutter שמציגה את האתר | Android / iOS |
| `bot/` | העברת שיעורים ותגובות מוואטסאפ לאתר | מחשב או שרת Node.js |

האתר והאפליקציה משתמשים באותו תוכן. הבוט מעלה תוכן לאותו אתר.
כתובת האתר הקיימת: https://rabbiyosefdanon.rabbiyosefdanon.workers.dev

## האתר

```bash
cd website
npx wrangler dev
# פרסום כאשר רוצים לעדכן את האתר:
npx wrangler deploy
```

נדרשת הרשאה לחשבון Cloudflare ולמאגר R2 בשם `rabbi-videos`.
יש לשחזר בנפרד את סודות ה-Worker והגדרות החשבון.

## האפליקציה

```bash
cd app
bash tool/setup.sh
flutter build apk --release
```

קובץ `codemagic.yaml` נמצא בשורש המאגר ומוגדר לבנות מתוך `app/`.
כדי לבנות דרך Codemagic יש לחבר אליו את המאגר החדש ולהגדיר את הרשאות וחתימות הבנייה.
ראו `app/README.md` לפרטים על חתימה ו-iOS.

## בוט וואטסאפ

```bash
cd bot
bash setup.sh
npm start
```

ההתקנה מבקשת סיסמת ניהול ויוצרת קובץ מקומי; בהפעלה ראשונה סורקים QR בוואטסאפ.
הסקריפט גם מכין שירות systemd מקומי. אין להריץ אותו על הבוט הפעיל רק בגלל מעבר למאגר זה.
`config.json`, תיקיית `auth/` ו-`seen.json` אינם נשמרים ב-Git.
